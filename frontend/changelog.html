Release history

All versions of Sporafind, in chronological order.

RSS feed
v1.2.0 Major
June 15, 2026

Pan-African scope expansion, new API endpoints, and organisation analytics. This release extends Sporafind's intelligence coverage from Ghana to all 54 African nations.

Added
  • Pan-African scope: search and segment diaspora profiles across all 54 African nations, not just Ghana
  • New /v2/people API endpoint with pagination, advanced filters, and bulk lookup support
  • /v2/organisations API endpoint with membership estimates, leadership signals, and engagement history
  • Organisation analytics dashboard — visual breakdowns of org types, geographic distribution, and growth trends
  • Multi-country export filter: filter and export profiles by any combination of countries
  • API key usage metrics in the dashboard with real-time rate limit monitoring
Improved
  • AI signal confidence scoring now calibrated per-country with region-specific training data
  • Search latency reduced by 40% across all profile types through query optimisation
  • Organisation profile cards now include founding year, registration number, and recent activity timeline
  • Wealth tier signals (HNW/UHNW) refined with additional data sources for all countries
Fixed
  • Fixed edge case where profiles with mixed-country signals were incorrectly geo-tagged
  • Resolved CSV export truncation for organisations with more than 5,000 membership records
  • Corrected rate-limit header values in API responses to reflect actual allowance
v1.1.0 Major
May 1, 2026

Organisation discovery engine, AI-powered outreach generation, and CRM integrations. The biggest leap in platform capability since launch.

Added
  • Organisation discovery engine — search diaspora associations, investment syndicates, professional bodies, community orgs, cultural groups, and think tanks
  • AI outreach generation: one-click personalised draft for any profile, factoring in segment, sector, location, and investment history
  • HubSpot and Salesforce CRM integration — push profiles and organisations directly from the platform
  • Notion and Airtable export connectors for team collaboration workflows
  • Organisation membership size estimates with confidence indicators
  • Saved search alerts — get notified when new profiles match your saved criteria
Improved
  • Profile cards redesigned with clearer segment badges, wealth tier indicators, and engagement readiness score
  • Search algorithm now indexes 3 additional public data sources for richer profile signals
  • Export speed improved 3x for large result sets (10,000+ records)
  • Mobile responsiveness of dashboard tables and profile cards
Fixed
  • Fixed bug where some leader profiles were incorrectly classified as entrepreneurs
  • Resolved duplicate profile entries appearing in multi-country search results
  • Fixed session expiry handling that caused intermittent logouts during long sessions
Deprecated
  • Legacy /v1/profiles endpoint marked for deprecation — migrate to /v2/people
  • CSV export v1 format (flat columns) deprecated in favour of v2 (nested segment data)
v1.0.1 Patch
April 10, 2026

Performance improvements, infrastructure hardening, and bug fixes following public launch feedback.

Improved
  • Profile search response times reduced by 35% through database query optimisation and caching
  • Image asset delivery migrated to CDN with global edge caching — 60% faster thumbnail loading
  • Dashboard initial load time improved by 50% with lazy-loaded components
  • API rate limit increased from 100 to 500 requests per minute for authenticated users
Fixed
  • Fixed pagination offset bug on organisation search results beyond page 20
  • Resolved 500 error when filtering by wealth tier with no results
  • Corrected timezone handling on profile "last active" timestamps
  • Fixed mobile navigation overlap issue on screens under 360px width
v1.0.0 Launch
March 20, 2026

Initial public launch. Sporafind is now available to everyone. The first complete platform for Ghanaian diaspora intelligence.

Added
  • People segmentation engine with four profile types: regular diaspora, leaders, entrepreneurs, and investors
  • AI-powered profile discovery across LinkedIn, Companies House, Crunchbase, news archives, and business registries
  • Wealth tier signals (HNW/UHNW) on investor and entrepreneur profiles
  • Interactive diaspora map with real-time profile counts per country and city
  • Keyword and semantic search — find profiles by name, industry, location, or natural language queries
  • CSV export with full profile data, segment labels, and confidence scores
  • API access (v1) for programmatic profile and organisation queries
  • Three pricing tiers: Starter ($49/mo), Growth ($199/mo), and Enterprise (custom)
Improved
  • Final pre-launch AI model training pass — signal accuracy improved from 91% to 94%
  • Onboarding flow refined based on beta user feedback (reduced from 6 steps to 3)
  • Documentation site launched at docs.sporafind.com with API reference and guides
Fixed
  • All critical and high-severity issues identified during beta testing resolved
  • Edge cases in name matching for Ghanaian names with tonal diacritics
v0.9.0 Beta
February 10, 2026

Beta release — available to a limited set of users for testing and validation. Core search and segmentation are functional.

Added
  • Beta user onboarding with guided product walkthrough
  • Feedback widget integrated directly into the dashboard for beta testers
  • Profile reporting tool — users can flag incorrect or outdated profile data
  • Usage analytics page showing search history, export count, and API consumption
Improved
  • AI segmentation accuracy improved with additional training on Ghanaian business naming conventions
  • Search relevance tuned — Ghana-origin signals now weighted 2x higher than secondary sources
  • Dashboard performance optimised for beta traffic load
Fixed
  • Fixed incorrect industry tagging for profiles in healthcare and education sectors
  • Resolved intermittent search timeout errors during peak usage hours
  • Corrected investor count discrepancy between dashboard and export data
v0.8.0 Alpha
January 5, 2026

Private alpha release. The first version of Sporafind — internal testing with select partners. Core intelligence engine operational.

Added
  • Initial AI intelligence engine capable of identifying Ghanaian diaspora profiles from public sources
  • Basic search interface with name, location, and keyword filters
  • Profile view with source attribution and confidence score
  • Authentication system with email-based signup and Google OAuth
  • Simple list export to CSV (flat format, 50-record limit)
  • Internal dashboard with basic profile count metrics
Improved
  • Initial data pipeline processing speed — reduced from 8 hours to 45 minutes per data refresh cycle
  • Internal search indexing for faster query response times
Fixed
  • Various early-stage data deduplication issues resolved
  • Fixed profile source URL parsing errors for international domain formats
